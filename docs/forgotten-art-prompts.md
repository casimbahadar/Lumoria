# Forgotten Lumori — Appearance / Art-Generation Prompts

The 39 Forgotten Lumori (ids 462–500) are the post-game legendaries of the lost realm **Vaeldris**, carried by its 13 **wielders** (3 each: a 720-BST base, a 750-BST mid, and an 800-BST "ace" that should read as a titan/god). Every entry below is built around a **concrete, drawable body plan** so sprites/art are straightforward.

**How to use:** paste the **Prompt** line into an image generator. Each block also lists **Form / Palette / Signature** if you want to tweak. A shared per-wielder **motif** keeps each trio visually like a "team."

**Rare-type color language (kept consistent):**
Aether = white-gold / opal / halos · Chrono = brass-clockwork / amber sand / pale-blue time-glow · Crystal = prismatic facets / gem-tones · Primal = earthen-amber / bone / magma · Stellar = indigo-violet / gold starlight · Dream = lavender-twilight.
